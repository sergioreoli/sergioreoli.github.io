Referência essencial

Git, sem complicação.

Os comandos mais usados para iniciar um repositório, acompanhar mudanças, desfazer alterações e trabalhar com branches.

01

Inicialização

git initInicializa um novo repositório Git no diretório atual.
git clone https://github.com/usuario/repositorio.gitClona um repositório remoto para o computador.
02

Alterações

git statusExibe o estado atual do repositório: arquivos modificados, novos e prontos para commit.
git add arquivo.txtAdiciona um arquivo específico à área de preparação (staging).
git add .Adiciona todas as alterações do diretório atual à área de preparação.
git commit -m "Descrição das alterações"Registra as alterações preparadas com uma mensagem no histórico local.
03

Reversão

git reset --soft HEAD~1Desfaz o último commit, mantendo as alterações na área de preparação.
git reset HEAD~1Desfaz o último commit e mantém as alterações nos arquivos, fora da área de preparação.
git checkout -- arquivo.txtDescarta alterações não confirmadas de um arquivo específico.
04

Branches (ramificações)

git branchLista as branches existentes no repositório.
git branch nome-da-branchCria uma nova branch.
git checkout nome-da-branchAlterna para uma branch existente.
git checkout -b nova-branchCria uma nova branch e muda para ela.
05

Publicação e atualização

git pullBusca atualizações do repositório remoto e integra as alterações à branch local.
git pushEnvia os commits locais para o repositório remoto, como o GitHub.
git fetchBusca informações e atualizações do repositório remoto sem integrá-las automaticamente à branch atual.

Observações importantes

  • Commit: registra uma versão das alterações no histórico local.
  • Push: publica os commits no repositório remoto, como o GitHub.
  • Pull: atualiza o repositório local com as alterações remotas.
  • Fetch: consulta atualizações remotas sem aplicá-las automaticamente.
  • Reset: exige atenção, pois dependendo da opção utilizada pode descartar alterações.
  • Checkout: comando tradicional que também pode ser substituído por git switch e git restore em operações específicas.
